How to Add, Edit & Manage Products

Centralized JavaScript Product Catalog

You do not need to write repetitive HTML. Simply open this index.html file in any code editor (VS Code, Notepad, Cursor) and locate the const PRODUCTS = [ ... ] array at the very top of the script tag.
Step 1:

Customize Beta 1 & 2

Change the names, taglines, and feature lists of the two pre-configured Beta products.

Step 2:

Choose Video Type

Set demoType to 'youtube', 'mp4', or 'canvas'.

Step 3:

Add New Products

Copy and paste any product block into the array. The catalog updates automatically.

Example Product Code Block to Copy: 
{
  id: "my-new-product",
  name: "Sunrise Workspace Cloud",
  tagline: "Autonomous background cloud backup and asset pipeline for engineering teams.",
  status: "beta",          // Available statuses: "beta" | "live" | "coming"
  badgeText: "v0.9 Beta",
  categoryLabel: "Cloud Tool",
  platforms: ["macOS", "Windows", "Linux"],
  specs: "Rust • Multi-Region • Zero-Knowledge",
  features: [
    "Continuous encrypted delta sync",
    "Sub-15ms webhook processing",
    "Single-click enterprise onboarding"
  ],
  demoType: "canvas",      // "youtube" | "mp4" | "canvas"
  demoUrl: "",             // e.g. "https://www.youtube.com/embed/dQw4w9WgXcQ"
  ctaText: "Request Beta Key"
},
